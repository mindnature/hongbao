# 微信红包封面平台边界与验收

官方入口：https://cover.weixin.qq.com/

此文档区分「本地可验证」与「平台才可确认」。2026-11-19 编写。页面随时可能调整。

## 本地可检查

- 静态图输出 957x1278、JPEG、最多 500,000 字节。这是参考开源流程采用的保守目标，不能代表平台所有封面类型的完整规范。
- 检查图片实际编码、尺寸和大小，保留原画与预览图供复核。
- 预览图只是模拟遮挡区域，不是官方裁剪结果。

## 平台必须核实

- 当前个人/企业注册资格，公众号、视频号粉丝及认证门槛。
- 实际页面支持的上传格式、大小、主体区域与封面简称条件。
- 肖像、原创作品、商标和证明材料要求；AI 生成内容需要提供什么。
- 是否要求封面故事/其它字段、具体审核结果、购买与领取有效期。
- 审核、购买和发放依赖微信开放平台，脚本无法保证结果。

## 安全规则

- 用户必须在可见浏览器本人扫码，并完成所有验证码或实名认证。
- 不使用私有接口、抓取 cookie、跳过反机器人保护或批量账号登录。
- 浏览器登录状态仅留本地的 .hongbao/browser-profile，不记录到日志、不入库。
- 不自动提交审核、不买数量、不发放，除非未来提供经过明确授权、可确认的单独操作。
- 页面存在多个图片上传框时，程序必须停止猜测，避免误将封面图传到 logo 或封面故事区域。

## 端到端验收清单

1. 测试环境安装 python -m pip install -e ".[all]" 及 python -m playwright install chromium。
2. 有效的 API 密钥测试纯文本生图和有授权的照片编辑；无密钥测试错误信息。
3. 为复杂原图导出 JPEG；自动检查输出严格符合限制。
4. 人眼检查原画及模拟预览，头像、按钮遮挡区域不覆盖关键元素。
5. 有资格的账号在正常浏览器中扫码登录；不导出登录态。
6. 在当前正式站点测试表单定位、唯一的封面上传 input、页面预览与保存。
7. 记录不同账号类型/错误提示/页面变化；在没有授权前不提交审核。
8. 必须明确对最终用户说明：是否实际上传成功，是否仅打开网站，是否仅本地制作。


## 动态素材（新增）

- MP4：根据公开资料，动态封面通常为1–3秒、H.264/AVC、yuv420p、≤30fps、≤3000kbit/s、≤20MB、3:4推荐。脚本使用960×1280、24fps；不将静态图957×1278的奇数宽度硬套到H.264 yuv420p。
- 动态封面 PNG 序列帧：957×1278、24fps、24–72张、连续五位编号ZIP≤50MB。
- 透明挂件 PNG 序列帧：1053×1746、24fps、24–72张、ZIP≤20MB；必须有透明区域。
- 动态文件上传控件尚未经正式账号测试。上传助手故意不自动猜测MP4/ZIP对应字段，必须由用户选定并确认。
- 在微信 App 中个人自制封面、微信红包封面开放平台定制、红包详情页「封面故事」之间存在不同素材规则，不要混淆。
